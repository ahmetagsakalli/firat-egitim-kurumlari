# Fırat Eğitim Kurumları Next.js Frontend

Modern, hızlı ve mobil uyumlu bir eğitim kurumu landing sayfası.

## Komutlar

```bash
pnpm install
pnpm optimize:images
pnpm dev
pnpm build
```

Görseller `work-assets` klasöründeki kaynak dosyalardan WebP olarak `public/images` altına üretilir. Sayfa App Router kullanır ve SEO metadata, sitemap, robots ve JSON-LD yapılandırması içerir.
